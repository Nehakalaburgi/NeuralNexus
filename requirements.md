# RESQALLOC FRONTEND REQUIREMENTS & OPERATIONAL SPECIFICATION

## 1. System Vision
Build a tactical, real-time Emergency Control Room dashboard ("ResQAlloc") to demonstrate AI-powered multi-agent dynamic triage, resource reallocation, and human-in-the-loop (HITL) approval gates to hackathon judges.

## 2. Functional Capabilities

### F1: Full-Screen Geospatial Awareness
- Full-viewport dark-themed Mapbox GL canvas centered on Bengaluru (`[77.5946, 12.9716]`, zoom 12.5).
- Pulsing SVG markers for emergencies:
  - Severity 5: Intense pulsing red ring with hazard icon.
  - Severity 3–4: Amber warning ring.
  - Severity 1–2: Subdued yellow/cyan indicator.
- Hospital markers with bed capacity readouts.
- Emergency vehicle markers with orientation, status tag, and type icon (Ambulance, Fire, Rescue).
- Interactive Route Polylines:
  - Active approved routes: Solid neon cyan with flow animation.
  - Pending reallocation routes: Dashed flashing amber vector.

### F2: Floating Hover-Expandable Panels
- **Left Panel (Active Incidents):**
  - Default: Sleek vertical strip displaying `🚨 [Active Count]`.
  - Hover: Expands to full list of `IncidentCard` items with Severity badge, timestamp, required resources, and target hospital. Clicking an incident triggers smooth `map.flyTo()`.
- **Right Panel (Fleet & Agent Telemetry):**
  - Upper section: Available vs. deployed resource meters.
  - Lower section: Terminal-style real-time agent telemetry stream displaying agent thoughts (`[TRIAGE]`, `[LOGISTICS]`, `[ALLOCATION]`, `[COMMAND]`).

### F3: Human-in-the-Loop (HITL) Reallocation Modal
- Triggers when `pendingApproval` is populated in the state.
- Presents:
  - Diverted unit ID (e.g., `AMB-01`).
  - Preempted incident (Level 1) vs. Target incident (Level 5).
  - Natural-language rationale generated by Gemini Command Agent.
  - Interactive Action: `[APPROVE REALLOCATION]` button (commits route switch) and `[REJECT / KEEP PLAN]` button.

### F4: Demo Control Dock (Pitch Facilitator)
- Floating dock at bottom-center with three instant demo states:
  - `[1. Normal Ingestion]`: Initial 2 incidents and 2 units dispatched smoothly.
  - `[2. Inject Disruption]`: AMB-02 breaks down + Level 5 crash appears at MG Road + Agent triggers reassessment.
  - `[Reset Grid]`: Restores initial benchmark state.
- Mode Switcher in top navigation bar: `[MOCK MODE]` / `[LIVE WS]`.

## 3. Non-Functional Requirements
- **Fluid 60fps Rendering:** Panel hovers and marker updates must not block the main thread.
- **Resilience:** Gracefully display a clear config overlay if `VITE_MAPBOX_TOKEN` is unset in `.env`.
- **Zero Build Errors:** Compliant with strict TypeScript, Vite bundling, and Tailwind CSS v4 `@import "tailwindcss";` standards.
